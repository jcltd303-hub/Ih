# Production Security Verification Baseline — 2026-09-17

## Scope

This baseline gates deployment while the production settlement hardening tranche is implemented.

Required checks on a fresh checkout:

```text
npm ci
npm run typecheck
npm run test:ci
npm run build
npm run functions:build
```

The GitHub Pages deployment workflow runs these checks in a dedicated `verify` job and does not reach the deployment job unless verification succeeds.

## Evidence

CI is the source of truth for the command results. This document deliberately does not mark the unchecked security properties as verified until the corresponding implementation and regression tests exist and pass.

## Release gate

Deployment must remain blocked until the following are demonstrated by code and automated tests:

1. Active server seeds are not readable by clients.
2. Payout-relevant target, fish tier, skin bonus, kill, and boss progression facts are server-authoritative.
3. Duplicate/retried requests cannot create duplicate financial effects.
4. Wallet, settlement, request-idempotency, target-dedupe, boss progression, and telemetry writes remain transactionally consistent.
5. Frontend and Functions verification gates pass.
