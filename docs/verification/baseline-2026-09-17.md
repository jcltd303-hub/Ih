## CI gate

The deployment workflow now runs the checks in this order:

1. Install root dependencies with `npm ci`.
2. Typecheck the application.
3. Run the root Vitest suite in CI mode.
4. Build the frontend/server bundle.
5. Install Functions dependencies and compile Functions with `npm run functions:build`.
6. Upload the Pages artifact only after all verification steps succeed.
7. Deploy Pages only for a successful push to `main`.

Pull requests run the verification job but do not deploy.
